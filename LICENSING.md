# Licensing Scope (mcpaql-adapter Repo)

This repository uses **split licensing**:

- **Documentation / prose**: Creative Commons Attribution 4.0 International (**CC BY 4.0**) — see `LICENSE-DOCS`.
- **Software artifacts**: GNU Affero General Public License v3.0 (**AGPL-3.0**) — see `LICENSE`.

If you are unsure which license applies to a file, use the path-based rules below.

## CC BY 4.0 applies to

Documentation and community text:

- `docs/`
- `README.md`
- `CHANGELOG.md`
- `CODE_OF_CONDUCT.md`
- `SECURITY.md`
- `CONTRIBUTING.md`
- `.github/`

## AGPL-3.0 applies to

Artifacts intended to be consumed by tooling/implementations:

- `src/`
- `tests/`
- `examples/`
- `schemas/`
- Any source code or scripts (e.g., `scripts/`, `tools/`)

Commercial licenses are available for organizations that prefer not to use the AGPL:

Organizations with less than $1,000,000 USD in annual revenue may self-certify for a free commercial license. See `COMMERCIAL-LICENSE.md` for details.
